# Rslook — instructions for agents

Rslook is a clean-room, open-source, Rust-native email, calendar and contacts client targeting
**Outlook classic** (Windows desktop Outlook) parity on Linux and Windows. It follows the
conventions of the ArtCraft Crafting Apps (see `../wordcraft/AGENTS.md`), which it is modelled on.

## Clean room (non-negotiable)
- Outlook classic may be **observed** black-box only: run it, use its UI with synthetic accounts
  and synthetic mail, and take screenshots **of its window only**, stored under
  `plan/outlook/screenshots/` (gitignored, never committed). Write what you observe in your own words.
  Capture with `scripts/outlook-shot.ps1 -Name <view>` (window handle only, never the desktop).
  Observed target: Outlook classic (Microsoft 365) 16.0.20527.20088, Windows.
- Use only a dedicated test account or local data with synthetic mail, never personal mail.
- **Never** read, decompile, disassemble, debug, hook, trace or copy anything inside the Office
  installation (`OUTLOOK.EXE`, DLLs, resources, registry blobs, templates). File names and listings only.
  Reverse-engineering tools (REA, Ghidra, IDA, Frida, …) are never pointed at Microsoft binaries.
- Never commit files produced by Outlook (`.pst`, `.ost`, `.msg`, `.oft`, exported data). Test
  fixtures are generated by our own code from the public specs.
- Never copy Microsoft wording beyond feature names and keyboard shortcuts.
- Formats and protocols come from public specs only: RFC 5322 / 2045-2049 (MIME), RFC 9051 (IMAP),
  RFC 5321 (SMTP), RFC 5545 (iCalendar), RFC 6350 (vCard), RFC 4791 / 6352 (CalDAV / CardDAV),
  Microsoft Open Specifications ([MS-PST], [MS-OXMSG], [MS-OXPROPS], [MS-OXCICAL], [MS-ASCMD],
  EWS, Microsoft Graph, Microsoft identity platform OAuth 2.0 (RFC 6749, RFC 7636 PKCE, RFC 8252),
  SASL XOAUTH2). Never copy GPL/LGPL/AGPL code (Thunderbird, Evolution, libpst, …).

## Assets: no Microsoft iconography
Never copy, trace, crop or recreate icons, images, sounds, themes or fonts from Outlook/Office.
Icons are drawn in code (`crates/ui-egui/src/icons.rs`) or are CC0 / OSI-licensed, each with a row
in `ATTRIBUTION.md`.

## Never crash
- No `unwrap()`, `expect()`, `panic!`, `unreachable!`, `todo!`, `unimplemented!` in non-test code;
  no `unsafe`. Production crate roots carry the `#![deny(clippy::unwrap_used, …)]` header.
- Errors are `Result<T, E>`. Input-derived data (mail, files, command params) is hostile: `get()`
  over indexing, char-boundary slicing, checked arithmetic, capped allocations.
- `crates/engine/src/tests.rs::hostile_params_never_panic` runs every command with junk params.

## Architecture
| Layer | Crate | Job |
|---|---|---|
| L1 | `mail` | Mail model (accounts, folders, messages, addresses), RFC 5322 parsing, store |
| L1 | `msg`, `pst` | Outlook file import: `.msg` ([MS-OXMSG], own reader on `cfb`) and the MAPI property mapping; read-only `.pst` ([MS-PST]) through Microsoft's MIT `outlook-pst` crate. Test fixtures come from our own writers (`fixtures` feature) |
| L2 | `account` | Account settings (IMAP/SMTP servers or Microsoft), accounts file, OS keychain (`SecretStore`: password or OAuth refresh token) |
| L3 | `imap`, `smtp` | IMAP client (async-imap, rustls) and SMTP submission (lettre), password or XOAUTH2 login |
| L3 | `oauth`, `graph` | Microsoft sign-in (OAuth 2.0 auth code + PKCE, loopback redirect, refresh) and a blocking Microsoft Graph mail client; each has an in-process mock server (`mock` feature) for tests |
| L4 | `engine` | `Session`, undo, **command registry**, Outlook feature catalog, sample data, offline change queue and sync jobs (`sync.rs`, no network code) |
| L5 | `sync` | Send/Receive worker: runs engine jobs against IMAP/SMTP or Microsoft Graph on a background thread; runs Microsoft sign-ins |
| L6 | `ui-egui` | Outlook-classic-style egui front end (ribbon, folder pane, list, reading pane) |
| apps | `apps/rslook` | Desktop binary (eframe + wgpu) |

Planned: `ical`, `vcard`.

- **Everything is a command.** User-visible behaviour is a `CommandSpec` in
  `crates/engine/src/cmd/*.rs`. The ribbon, shortcuts and (later) CLI/MCP dispatch by id.
- **Parity is measured** in `crates/engine/src/catalog.rs` (Outlook classic ribbon features →
  command ids).
- Nothing below L6 depends on egui/eframe/winit.

## Quality gates
`cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test` before every commit.
GitHub Actions (`.github/workflows/ci.yml`) runs the same three, plus `scripts/mail-test.sh`, on every push to `dev`/`main` and on pull requests. Each new stage adds its tests there.
Send/Receive changes: also `scripts/mail-test.sh` (throwaway GreenMail, Dovecot and Mailpit servers, synthetic mail).
Headless screenshot: `cargo run -p rslook-ui-egui --example ui_shot -- /abs/out.png`.
